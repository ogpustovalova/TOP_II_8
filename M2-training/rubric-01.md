# Рубрика 2.1 — Backprop и обучение сети

Шкала оценивания — **единая 100-балльная БРС УрФУ** (см. [`docs/internal/urfu-program-facts.md`](../docs/internal/urfu-program-facts.md)):
уровни **В** (Высокий), **С** (Средний), **П** (Пороговый), **Н**
(Недостаточный). Порог зачёта — **40 баллов**.

| Критерий | Вес | П | С | В |
|---|:---:|---|---|---|
| **Корректность backprop (NumPy)** | 35 | Ручной backprop двухслойной сети работает; формула $\theta \leftarrow \theta-\mathrm{lr}\nabla L$ реализована; loss убывает; численный gradient check хотя бы одного параметра согласуется с аналитическим | То же + корректно выведены производные softmax + cross-entropy и разобрана относительная ошибка gradient check | То же + обобщение на произвольную глубину и анализ численной устойчивости |
| **Loss, пакет и конфигурация** | 20 | Реализованы multiclass `CrossEntropyLoss` и binary `BCEWithLogitsLoss` с корректными logits/targets и отклонением несовместимых альтернатив; для 10/50/200/500 есть таблица validation loss/metric, времени и обновлений, предзаданное правило и выбор без test leakage; сравнены `ReLU + He`, `tanh + Xavier`, один/два слоя и контролируемая пара плотной/фиксированной 50%-разреженной связности с долей активных связей и выбором по validation | То же + выводы отделяют влияние loss, размера пакета, активации, инициализации, глубины и связности | То же + устойчивость выбора проверена на нескольких seed без изменения правила |
| **Переобучение и регуляризация** | 25 | Переобучение показано; baseline, Dropout и L2 обязательны и сравнены; EarlyStopping восстанавливает лучшие веса; минимум две силы одного регуляризатора сравнены и одна выбрана по validation | То же + выбор обоснован validation loss/метрикой и разрывом train/validation | То же + устойчивость выбранной силы подтверждена на нескольких seed |
| **Понимание (защита)** | 20 | Объясняет правило цепи; full-batch/mini-batch/stochastic GD; форматы обоих loss; роль `batch_size`; механизмы Dropout и L2; выбор активации, связности и инициализации | То же + выводит градиент по слою и объясняет число/шум обновлений для разных пакетов | То же + обсуждает затухание/взрыв градиента и ограничения проведённых сравнений |

Балл по критерию: Н = 0; П = 50 % веса; С = 75 %; В = 100 %.
Итог БРС равен сумме баллов критериев без дополнительного минимального уровня по
каждой строке. Обычный порог зачёта остаётся равным 40 баллам, поэтому весь
диапазон уровня БРС П 40–59 достижим. Компенсация баллов внутри БРС не заменяет
отдельный некомпенсируемый шлюз вклада в уровень С КРМ ниже.
Если «Понимание (защита)» оценено на Н, итог БРС ограничивается 39 баллами.

## Бинарный шлюз вклада M2 в DL-1.1 уровня С КРМ

Эта матрица не начисляет баллы и не ограничивает балльный итог БРС. Для каждой
строки преподаватель фиксирует 1 только при наличии наблюдаемого артефакта и
подтверждения на защите.

| Компонент M2 | Наблюдаемое свидетельство | 0/1 |
|---|---|:---:|
| Ручной backprop | NumPy forward/backward, правило цепи, обновление весов, убывающий loss | |
| Активация, связность, инициализация | Единая validation-таблица `ReLU + He`, `tanh + Xavier`, одного/двух слоёв и плотной/фиксированной 50%-разреженной связности; указана доля активных связей и обоснован выбор | |
| Выбор функции потерь | Реально обучены multiclass CE и binary BCEWithLogits с верными форматами; несовместимые варианты отклонены с объяснением | |
| Выбор `batch_size` | Таблица 10/50/200/500 с validation loss/metric, временем и обновлениями; правило задано заранее, выбор сделан без test | |
| Регуляризация и прореживание | Baseline, Dropout, L2 и EarlyStopping сравнены; не менее двух сил одного регуляризатора, выбор по validation | |
| Понимание градиентного спуска | Формула шага, различия full-batch/mini-batch/stochastic GD и численный gradient check | |

Шлюз вклада M2 равен 1 только при значении 1 во **всех** строках; баллы между
строками не компенсируются. Полный уровень С DL-1.1 КРМ подтверждается только
при `шлюз M2 = 1` **и** `шлюз M7 = 1`; шлюз M7 проверяет выбор `lr` в зависимости
от задачи и данных. Уровень **С БРС** (60–79 баллов ниже) — другая шкала и сам по
себе не означает уровень **С КРМ**.

## Контроль устной защиты

Обязательна. Минимальный набор вопросов — в
[`kim-01-backprop-training.md`](kim-01-backprop-training.md). Неответ учитывается
при выборе уровня критерия «Понимание (защита)»; отказ по более чем двум
вопросам означает Н по этому критерию.

## Уровни БРС и балльная нормировка

| Уровень (БРС УрФУ) | Баллы | Традиционная оценка | Зачёт |
|---|---|---|---|
| **В** (Высокий) | 80–100 | Отлично | Зачтено |
| **С** (Средний) | 60–79 | Хорошо | Зачтено |
| **П** (Пороговый) | 40–59 | Удовлетворительно | Зачтено |
| **Н** (Недостаточный) | < 40 | Неудовлетворительно | Не зачтено |

Порог положительного балльного результата КИМ — **40 баллов** (уровень не ниже
П); подтверждение DL-1.1 С и зачёт по дисциплине дополнительно требуют шлюзы,
описанные выше и в общей методике оценивания.
