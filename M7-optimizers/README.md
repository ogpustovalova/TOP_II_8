# Модуль 7. Алгоритмы обучения нейронных сетей

Раздел РПД №7. Алгоритмы обучения нейронных сетей: современные оптимизаторы
(SGD с моментом, Adam, AdamW, RMSProp), выбор начальной скорости обучения под
задачу, датасет и архитектуру, управление скоростью обучения (lr scheduling),
ранняя остановка. Воспроизводимый КИМ закреплён за **PyTorch, Fashion-MNIST и
фиксированной MLP**.

## КИУ (КРМ v3.0)

| Компетенция | Индикатор | Уровень |
|---|---|:---:|
| DL-1. Архитектуры глубоких НС | DL-1.1 — математические основы НС | С (если `шлюз M2 = 1` и `шлюз M7 = 1`) |

M7 даёт обязательный вклад в подтверждение уровня **С КРМ**: студент понимает
базовый шаг градиентного спуска и экспериментально задаёт/выбирает скорость
обучения в зависимости от выбранных задачи, набора данных и архитектуры. Выбор
делается по validation, до просмотра test, и проверяется на нескольких seed.
Для protocol-fair сравнения каждый из пяти оптимизаторов получает отдельную
сетку одинакового размера минимум из трёх подходящих initial `lr`: сначала по
validation выбирается `lr` каждого алгоритма, затем сравниваются пять настроенных
оптимизаторов.

Это **не самостоятельное полное подтверждение DL-1.1 С**. Выбор функции потерь,
`batch_size`, регуляризации и Dropout проверяется шлюзом M2. Полный уровень
DL-1.1 С фиксируется только при одновременном выполнении `шлюз M2 = 1` и
`шлюз M7 = 1`; условия шлюза M7 описаны в [рубрике](rubric-01.md).
