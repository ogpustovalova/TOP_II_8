# Банк квизов для самопроверки

Необязательные короткие квизы для самостоятельной проверки понимания до сдачи
лабораторных и рубежных срезов. **Не входят** в балльную оценку ФОС и не
заменяют К1/К2, лабораторные или зачёт. Ключи приведены в конце каждого квиза;
рекомендуется сначала ответить, затем свериться.

Формат: закрытые вопросы (один верный ответ, если не указано иное) и короткие
открытые. Уровень — базовый (Б) по соответствующим КИУ. Всего **10 квизов**.

---

## Квиз 1. Нейрон и активации (M1)

1. Почему композиция нескольких линейных слоёв без нелинейной активации
   эквивалентна одному линейному преобразованию?
   - A) Потому что веса суммируются
   - B) Композиция аффинных преобразований остаётся аффинным
   - C) Из-за затухания градиента
   - D) Из-за BatchNorm

2. Чем насыщение sigmoid отличается от поведения ReLU при положительных входах?
   - A) У sigmoid производная мала на больших по модулю входах; у ReLU при
     $x>0$ производная равна 1
   - B) ReLU всегда затухает сильнее sigmoid
   - C) Sigmoid не ограничена сверху
   - D) Нет различий

3. Почему инициализация всех весов нулями — плохая идея для скрытых слоёв?
   - A) CUDA не поддерживает нули
   - B) Симметрия: нейроны получают одинаковый градиент и не разделяют роли
   - C) Нули запрещены в autograd
   - D) Loss сразу становится NaN

4. Открытый: зачем нужен bias (смещение) в линейном слое?

**Ключ:** 1-B, 2-A, 3-B; bias сдвигает решающую гиперплоскость / активацию
независимо от входа.

## Квиз 2. Backprop и обучение (M2)

1. Зачем вызывать `optimizer.zero_grad()` перед обратным проходом?
   - A) Чтобы обнулить веса
   - B) PyTorch накапливает градиенты в `.grad`; без обнуления они складываются
   - C) Чтобы сбросить momentum
   - D) Это требование CUDA

2. Почему в PyTorch перед `CrossEntropyLoss` обычно не применяют внешний
   `Softmax`?
   - A) Softmax уже внутри `CrossEntropyLoss` (численно устойчивый log_softmax)
   - B) Softmax запрещён библиотекой
   - C) Softmax нужен только для регрессии
   - D) Softmax увеличивает число параметров

3. Как слишком большая и слишком малая скорость обучения проявляются на кривой
   loss?
   - A) Большой lr — колебания, рост или NaN; малый — медленное почти плоское
     снижение
   - B) Большой lr всегда лучше
   - C) Малый lr даёт NaN
   - D) Скорость обучения не влияет на loss

4. Открытый: напишите формулу binary cross-entropy для одного объекта
   ($p=\sigma(z)$, метка $y\in\{0,1\}$).

**Ключ:** 1-B, 2-A, 3-A; BCE: $L=-(y\log p+(1-y)\log(1-p))$.

## Квиз 3. MLP и регуляризация (M3)

1. Что утверждает универсальная теорема аппроксимации и какое у неё практическое
   ограничение?
   - A) Любая непрерывная функция на компакте приближается MLP достаточной
     ширины; существование ≠ находимость оптимальных весов
   - B) Любая сеть с ReLU глобально оптимальна
   - C) Глубина всегда лучше ширины
   - D) MLP не может аппроксимировать нелинейные функции

2. Чем L2-регуляризация отличается от Dropout на этапе инференса?
   - A) L2 продолжает сжимать веса; Dropout на eval отключён
   - B) Dropout на eval усиливается
   - C) Нет различий
   - D) L2 работает только с CNN

3. Почему early stopping смотрят по validation, а не по train loss?
   - A) Train loss всегда растёт
   - B) Train loss может падать при переобучении; validation отражает обобщение
   - C) Validation быстрее считается
   - D) Так требует PyTorch

4. Открытый: зачем нужен validation set, если уже есть test?

**Ключ:** 1-A, 2-A, 3-B; validation — выбор гиперпараметров без test; test —
однократная итоговая оценка.

## Квиз 4. CNN (M4)

1. Формула размера выхода свёртки при входе $W$, ядре $K$, padding $P$,

   - A) $W-K+1$
   - B) $\lfloor(W-K+2P)/S\rfloor+1$
   - C) $W/S$

2. Зачем residual connection в ResNet?
   - A) Уменьшает число параметров
   - B) Создаёт короткий путь для сигнала и градиента, упрощая обучение глубоких
     сетей
   - C) Заменяет BatchNorm
   - D) Увеличивает receptive field в два раза

3. Чем global average pooling отличается от flatten перед классификатором?
   - A) GAP усредняет карту признаков, обычно меньше параметров и переобучения
   - B) Flatten всегда лучше GAP
   - C) GAP увеличивает число параметров
   - D) Нет различий

4. Открытый: чем feature extraction отличается от fine-tuning при transfer
   learning?

**Ключ:** 1-B, 2-B, 3-A; feature extraction — замороженный backbone + обучаемая
голова; fine-tuning — разморозка части/всех слоёв с малым lr.

## Квиз 5. RNN и единичная задержка (M5)

1. Что хранит блок единичной задержки в vanilla RNN?
   - A) Только вход $x_t$
   - B) Скрытое состояние $h_{t-1}$, которое становится входом шага $t$
   - C) Градиент loss
   - D) Embedding-матрицу

2. Формула перехода vanilla RNN:
   - A) $h_t = f(W_x x_t + W_h h_{t-1} + b)$
   - B) $h_t = W_x x_t$ без рекуррентности
   - C) $h_t = x_t + h_{t-1}$ без весов
   - D) $h_t = \mathrm{softmax}(x_t)$

3. Чем LSTM принципиально отличается от vanilla RNN?
   - A) Отсутствием скрытого состояния
   - B) Отдельным cell state и гейтами (вход, забывание, выход)
   - C) Только большим числом параметров без гейтов
   - D) Использованием только 1D-свёртки

4. Открытый: зачем `pack_padded_sequence` (или lengths) в RNN?

**Ключ:** 1-B, 2-A, 3-B; чтобы padding не участвовал в рекуррентном шаге и не
искажал состояние.

## Квиз 6. Attention и трансформер (M5)

1. Чем self-attention отличается от рекуррентного переноса $h_{t-1}\to h_t$?
   - A) Attention на каждом шаге может напрямую взвешивать все позиции
   - B) Attention не использует веса
   - C) RNN всегда быстрее attention
   - D) Нет различий

2. Зачем в scaled dot-product attention делят на $\sqrt{d_k}$?
   - A) Чтобы уменьшить число параметров
   - B) Стабилизировать скалярные произведения при большом $d_k$, иначе softmax
     насыщается
   - C) Это требование CUDA
   - D) Чтобы заменить positional encoding

3. Зачем positional encoding в трансформере?
   - A) Увеличить число голов
   - B) Attention перестановочно-инвариантен; PE задаёт порядок токенов
   - C) Заменить Embedding
   - D) Только для генерации изображений

4. Открытый: напишите формулу scaled dot-product attention.

**Ключ:** 1-A, 2-B, 3-B;
$\mathrm{Attention}(Q,K,V)=\mathrm{softmax}(QK^{\top}/\sqrt{d_k})V$.

   - D) Для ускорения inference

2. Что измеряет reconstruction loss автокодировщика?
   - A) Только KL
   - B) Ошибку восстановления входа из латентного кода (MSE и др.)
   - C) Accuracy на test
   - D) Learning rate

3. Что такое latent space в AE/VAE?
   - A) Слой Dropout
   - B) Сжатое представление входа в меньшей размерности
   - C) Только последний fully-connected слой классификатора
   - D) Буфер GPU

4. Открытый: что измеряет KL-член в функции потерь VAE?

**Ключ:** 1-B, 2-B, 3-B; KL приближает распределение латентных кодов к prior
(обычно $\mathcal{N}(0,I)$), регуляризуя латентное пространство.
